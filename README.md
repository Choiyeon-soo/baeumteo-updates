# 우리반 배움터 업데이트

특수학급 수업용 프로그램 「우리반 배움터」의 업데이트 파일을 두는 곳입니다.

- 배움터(v1.6.3 이상)가 켜질 때 이 저장소의 최신 릴리스에서 `latest.json`(버전 번호)과 `baeumteo-update.baeumup`(업데이트 파일)을 받아 갑니다.
- 업데이트 파일은 만든 사람의 키로 서명되어 있습니다. 서명이 맞지 않는 파일은 배움터가 받지 않습니다.
